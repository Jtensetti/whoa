# Whoa Search

An independent search index of publicly accessible Whoa.nu forum threads, with source links.

This repository contains a cautious crawler and search interface. The index is **not complete** until the crawl has finished and coverage has been audited.

## Deployment

See `render.yaml` for a persistent Render deployment. Crawl respects robots.txt and has a conservative delay. Service and disk may incur charges. Do not apply infrastructure changes before reviewing pricing.
